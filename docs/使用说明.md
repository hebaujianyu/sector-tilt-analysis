# 扇区Tilt分析工具箱 — 使用说明

> QGIS 插件 · 扇区垂直波瓣（Tilt）分析 + 环向阻挡剖面（45°×8）  
> |  |  |  
> | --- | --- |  
> 版本：v0.4.16　|　适用：QGIS 3.34 及以上（Windows）

---

## 一、插件能做什么

| 功能               | 说明                                                                      |
| ---------------- | ----------------------------------------------------------------------- |
| **点选传参出图**       | 在地图上点一下扇区/工参要素，自动解析小区号（CGI → 基站号+小区号 → 小区号），从工参图层反查 RF 参数，自动填入并运行垂直波瓣分析 |
| **手动参数分析**       | 直接输入经纬度、挂高、机械/电子下倾、波束宽度，生成垂直波瓣剖面（地形 + 主/上/下波束 + 遮挡点）                    |
| **环向剖面 (45°×8)** | 以一点为中心，8 个方向各生成一条独立地形剖面 + 中心阻挡玫瑰图，一眼看出哪个方向有山体遮挡                         |
| **下倾优化**（进阶）     | 按最大覆盖 / 目标距离 / 均匀覆盖自动搜索最优总下倾                                            |

所有数据**本地处理**，地形高程支持 **Open-Meteo 在线** 与 **本地 DEM 离线** 两种来源，可随时切换并一键「设为默认」（详见 3.5 节）。

## 二、安装

### 方式 1：从 ZIP 安装（推荐）

1. 打开 QGIS → 菜单栏 **插件 → 管理并安装插件**
2. 左侧选 **从 ZIP 安装** → 选择 `sector_tiltm_auto-0.4.16.zip` → **安装插件**
3. 安装完成后**重启 QGIS**

### 方式 2：手动解压

1. 把 zip 解压，得到文件夹 `sector_tiltm_auto`
2. 复制到 QGIS 插件目录：
   ```
   %APPDATA%\QGIS\QGIS3\profiles\default\python\plugins\
   ```
   （整条路径通常是  
   `C:\Users\<用户名>\AppData\Roaming\QGIS\QGIS3\profiles\default\python\plugins\sector_tiltm_auto`）
3. 重启 QGIS → **插件 → 管理并安装插件 → 已安装** → 勾选 **Sector TiltM Auto**

### 环境要求

- QGIS 3.34+（自带 Python 即可，无需额外安装）
- 建议加载一个**底图**（如 OSM/天地图）和一个**扇区/工参矢量图层**（GPKG/Shapefile 均可）

## 三、使用步骤

### 3.1 点选传参（最常用，一键出图）

1. 在图层面板中**打开**扇区/工参图层（图层必须处于可见状态）
2. 点击工具栏上的插件图标「**扇区点选分析**」（唯一图标，可勾选）
3. 在地图上**单击任意扇区要素**：
   - 自动解析小区号 → 查工参 → 带入经纬度/挂高/下倾/波束宽度
   - 自动弹出工具箱窗口并运行分析，直接出垂直波瓣剖面
4. 再点别处可连续分析；点空地只会在状态栏提示，不会报错
5. 分析完把图标取消勾选即恢复普通地图操作

> 工参图层支持三种小区号写法：CGI（如 `46000-3286202-202`）、基站号+小区号  
> 分字段（`gNodeBID`/`基站号` + `CellID`/`小区号`）、组合字段（`UniqueID`/`Cnum`）。  
> 字段名中英文均可（经度/longitude、挂高/height 等）。

### 3.2 手动参数分析

1. 菜单栏 **插件 → 扇区Tilt分析 → 扇区Tilt分析工具箱…**
2. 在左*侧「站点与射频参数」填入：*
   - ***纬度 / 经度****（WGS84 十进制度）*
   - **Azimuth** 方位角（°）
   - **天线挂高**（m）、**机械下倾 / 电子下倾**（°，总下倾自动求和）
   - **垂直/水平波瓣角**（°）
3. 「分析与数据源」里设定**最大距离**（默认 2000 m）
4. 点 **运行分析** → 右侧出垂直波瓣剖面图

### 3.3 环向剖面（45°×8 阻挡分析）

1. 菜单栏 **插件 → 扇区Tilt分析 → 环向剖面分析 (45°×8)…**
2. 取点（二选一）：
   - 点 **在地图上点选取点**，再到地图上单击（点到要素会顺带带入 RF 参数，点到空地只取经纬度）
   - 或直接输入经纬度 + 挂高/下倾/波束宽度
3. 点 **生成环向剖面** → 右侧九宫格：8 个方向独立剖面（按罗盘方位排列）+ 中心阻挡玫瑰图
4. 左侧表格汇总每个方向的首次遮挡距离与结论

### 3.4 参数速查

| 参数      | 含义                     | 典型值                    |
| ------- | ---------------------- | ---------------------- |
| 纬度/经度   | 站点位置（WGS84）            | 39.904200 / 116.407400 |
| Azimuth | 天线方位角                  | 0~359.99°              |
| 天线挂高    | 天线离地面高度                | 20~45 m                |
| 机械下倾    | 天线下倾（机械）               | 0~8°                   |
| 电子下倾    | 天线下倾（电子，Ret）           | 0~6°                   |
| 垂直波瓣角   | 垂直半功率角                 | 6~10°                  |
| 最大距离    | 剖面分析半径                 | 1000~2000 m            |
| 地形源/DEM数据源 | 本地 DEM (离线) / Open-Meteo (在线) | 有本地 DEM 优先本地 |

### 3.5 数据源切换与「设为默认」

地形高程有两个来源，各有适用场景：

| 来源 | 优点 | 缺点 |
|---|---|---|
| **本地 DEM (离线)** | 秒级出图、可断网、无配额限制 | 需在 QGIS 工程里先加载 DEM/DSM 栅格图层 |
| **Open-Meteo (在线)** | 无需准备数据、全球覆盖 | 服务器在国外、速度受网络影响，**每日有免费配额，超限当天不可用** |

**切换方法**：两处下拉都一样操作——

- **Tab1 扇区Tilt分析**：左侧「分析与数据源」分组的 **「DEM数据源」** 下拉
- **Tab2 环向剖面**：左列参数区底部的 **「地形源」** 下拉

**设为默认（推荐一次设好）**：每个下拉右侧有一个 **★** 小按钮——

1. 先把下拉切到你要的选项（如「本地DEM (离线)」）
2. 点旁边的 **★**，按钮由灰星变金星，同时地图上方弹提示「已把【××】设为默认」
3. 以后每次打开工具箱自动就是它，不用再切

> ★ 保存的选择存在 QGIS 全局设置里，跨工程、重启 QGIS 都有效。
> 未设过默认时，插件会智能选择：工程里已加载 DEM/DSM 栅格 → 自动用本地；没有 → 才用在线。

**推荐的本地 DEM 准备**：下载 Copernicus DEM 30m（免注册）或 ASTER GDEM 30m GeoTIFF，拖进 QGIS 即可；天津区域可参考 `F:\01_天津移动项目\DEM\README.md`，其中 `天津_DSM_合成30m.tif` 含建筑高度，市区遮挡分析效果最好。

- **中心玫瑰图**：8 方向遮挡距离极坐标图，越长=该方向越畅通

## 五、常见问题

| 现象             | 原因与处理                                                        |
| -------------- | ------------------------------------------------------------ |
| **分析执行很慢（十几秒甚至更久）** | 大概率在用 **Open-Meteo 在线数据源**（服务器在国外，网络不畅时单次请求最长等 30 秒）。**解决办法：把「DEM数据源 / 地形源」切到「本地DEM (离线)」并点右侧 ★ 设为默认**，分析速度提升到秒级且可完全离线（见 3.5 节）。覆盖地图的天地图影像底图加载也会占用几秒，属正常现象 |
| **在线模式弹「今日配额已用尽」** | Open-Meteo 免费接口**按 IP 限每日请求量**，超限当天不再可用（共享网络出口更容易被用光）。v0.4.16 起会立刻报错并给出中文提示，不再反复重试卡住界面。**处理：切「本地DEM (离线)」**，或等次日配额恢复 |
| **点选扇区后数据源被改回「在线」** | v0.4.15 及更早版本每次点选传参会强制重置数据源。v0.4.16 起尊重你 ★ 保存的默认，不会再被改；升级插件即可 |
| 点选后提示"未找到矢量要素" | 点在了空地或目标图层未勾选可见。请点在扇区/工参要素上，并确认图层树中该图层可见                     |
| 提示"未找到工参图层"    | 工程里没有带经纬度字段的矢量图层。请加载工参表；或通过 项目属性 → 变量 设置 `@gongcan_layer` 指定 |
| 某参数显示"未识别"     | 该字段名不在候选清单。把实际字段名反馈给维护者补充，或手填                                |
| DEM 在线失败       | v0.4.16 起失败即提示、不再长等；离线环境请在工程加载 DEM 栅格并切「本地DEM (离线)」+ ★ 设为默认   |
| 分析弹英文报错        | v0.4.13 起已修复（无 DEM 自动生成锚点）。若仍出现请升级到最新版                       |
| 工程里有多张栅格（DEM/DSM/底图），分析用哪张？ | 插件取工程里**第一个非底图栅格**。建议**一次只加载一张**要用于分析的高程图层（如 `天津_DSM_合成30m.tif`），其余移除或改名含 `map`/`basemap`/`三维` 等关键词（会被当底图跳过） |
